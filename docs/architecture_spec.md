# Technical Specification: Operators, Invariants, and Topological Boundaries

This document formalizes the measure-theoretic principles, structural operators, and invariants implemented across the econometric pipeline to prevent temporal leakage and filtration contamination[cite: 1].

---

## 1. Problem Formulation & Measure-Theoretic Preliminaries

Let $(\Omega, \mathcal{F}, (\mathcal{F}_t)_{t \ge 0}, \mathbb{P})$ be a filtered probability space satisfying the usual conditions, where $\mathcal{F}_t$ denotes the natural market filtration generated by the observable historical price and order flow processes up to time $t$[cite: 1]:
$$\mathcal{F}_t = \sigma\left(\{P_s, V_s, \text{Depth}_s : 0 \le s \le t\}\right)$$

A non-causal predictive or trading decision rule is defined as an $\mathcal{F}$-adapted functional[cite: 1]:
$$f: \mathcal{X}_t \to \hat{Y}_{t, h}$$
where $\mathcal{X}_t \in \mathbb{R}^K$ represents the candidate predictor space measurable with respect to $\mathcal{F}_t$[cite: 1], and $\hat{Y}_{t, h}$ is a forecast over the future horizon $(t, t+h]$[cite: 1].

**Filtration Contamination Axiom:** If any component $X_{j, t} \in \mathcal{X}_t$ satisfies $\sigma(X_{j, t}) \not\subseteq \mathcal{F}_t$, the pipeline incurs informational leakage, yielding invalid out-of-sample risk estimation[cite: 1].

### 2.1 The Forward-Compounded Total Return Synthesizer

* **Failure of Backward Adjustment (Theorem 1):** Traditional retrospective adjusted prices $\tilde{P}_t = P_t \times \prod_{k \ge t}^T \gamma_k$ violate causality because $\gamma_k$ (for $k > t$) depends on future corporate distributions $C_k = (S_k, D_k)$[cite: 1]. Hence, $\sigma(\tilde{P}_t) \subseteq \mathcal{F}_T \not\subseteq \mathcal{F}_t$[cite: 1].
* **Specification (Definition 2):** Given raw transaction price $P_t$, cash dividend $D_t$, and split multiplier $S_t$, we evaluate the point-in-time discrete return[cite: 1]:
  $$R_t = \frac{P_t + D_t}{P_{t-1} \cdot S_t} - 1.0$$
* **Synthetic Capitalization Index:**
  $$P_0^{\text{adj}} = 1000.0, \quad P_t^{\text{adj}} = P_0^{\text{adj}} \prod_{i=1}^t (1.0 + R_i)$$
* **Contemporaneous Envelope Projection:** High, Low, and Open series are adjusted contemporaneously via the scalar projection $\omega_t = P_t^{\text{adj}} / P_t$, ensuring price bounds remain strictly $\mathcal{F}_t$-adapted[cite: 1].

### 2.2 The Quarantine Projection Operator $\mathcal{Q}$

* **Specification (Definition 3):** Let $\mathcal{D}_t$ be the raw data tensor containing candidate predictors, targets, and intermediate artifacts[cite: 1]. The projection operator $\mathcal{Q}: \mathcal{D}_t \to \mathcal{X}_t$ maps $\mathcal{D}_t$ to the sanitized predictor space[cite: 1]:
  $$\mathcal{Q}(\mathcal{D}_t) = \mathcal{D}_t \setminus \mathcal{M}_t^{\text{quarantine}}$$
* **Quarantined Artifact Topology:**
  $$\mathcal{M}_t^{\text{quarantine}} \equiv \left\{ Y_t, R_t^{\text{barrier}}, \tau_t^{\text{touch}}, \text{barrier\_type}, \hat{\sigma}_t, S_t, D_t \right\}$$
* **Structural Guarantees:**
  1. **Dynamic Parameter Insulation:** Prevents volatility parameters $\hat{\sigma}_t$ (used to scale barriers) from entering predictor transformations[cite: 1].
  2. **Touch-Time Isolation:** Prevents model access to premature exit timestamps $\tau_t^{\text{touch}}$[cite: 1].
  3. **Zero Backward Imputation:** Disallows `bfill()` on missing series, requiring rolling forward estimators[cite: 1].

---

### 2.3 The Universal Lag Operator $\mathcal{L}$ (Global Shift-1 Lock)

* **Specification:** For all stateless rolling indicators, the universal lag operator enforces[cite: 1]:
  $$\mathcal{L}: X_t^{\text{stateless}} \mapsto X_{t-1}^{\text{stateless}}$$
* **Operational Invariant:** Any predictor vector indexed at session $t$ contains exclusively information observed and finalized by the settlement close of session $t-1$[cite: 1].
* **Execution Boundary:** When predicting target event $Y_t$ spanning horizon $(t, t+h]$, the decision function operates with zero exposure to same-day execution period mechanics[cite: 1].

## 3. Stateful vs. Stateless Feature Partition

| Dimension | Stateless Pipeline[cite: 1] | Stateful Pipeline[cite: 1] |
| :--- | :--- | :--- |
| **Mathematical Definition** | Pure backward operators over fixed rolling windows $W$[cite: 1]. | Distribution-dependent estimators parameterized by global samples[cite: 1]. |
| **Representative Features** | Kinematics ($v, a, j$), Shadow Rejection, Rolling CMF, VPT[cite: 1]. | Optimal Fractional Differencing ($d^*$), 2-Component GMM Regimes[cite: 1]. |
| **Cross-Fold Treatment** | Computed over rolling lookback buffer without fold fitting[cite: 1]. | Estimated **strictly on training partitions**; parameters frozen for test inference[cite: 1]. |
| **Leakage Risk** | Contemporaneous execution settlement ambiguity[cite: 1]. | Lookahead distributional shifts and future regime contamination[cite: 1]. |
| **Defensive Invariant** | Universal Shift-Lock $\mathcal{L}$ ($t \to t-1$)[cite: 1]. | $\Theta_{\text{train}}$ frozen into immutable convolution weights[cite: 1]. |

## 4. Purged Cross-Validation Architecture

To guarantee valid statistical risk estimation over serially dependent observations, the evaluation scheme enforces:

```
Fold k: [────── Train Window (N_train <= 750) ──────] [Purge Gap >= h] [─── Test (N_test) ───]
                             ▲
[Historical Lookback Buffer] ┘ (Warm-up only)
```

1. **Purge Gap ($\ge h$):** Eliminates label overlap between the training partition's right boundary and the test partition's left boundary[cite: 1].
2. **Historical Buffer ($N_{\text{buffer}} = 60$):** Prepended strictly to warm up rolling and fractional differencing convolutions, eliminating NaNs without leaking test feedback[cite: 1].
